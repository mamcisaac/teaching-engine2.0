## 📚 Comprehensive Glossary

### Educational & ETFO Terminology

**Assessment FOR Learning (AFL)**  
Ongoing assessment during instruction to inform teaching decisions and provide feedback to students.

**Assessment AS Learning (AAL)**  
Self-assessment and peer assessment that develops students' metacognitive abilities.

**Assessment OF Learning (AOL)**  
Summative assessment that evaluates student achievement at the end of a learning period.

**Curriculum Expectation**  
A specific learning standard from the Ontario curriculum that describes what students should know and be able to do.

**Daybook Entry**  
Daily reflection and documentation of teaching and learning progress, part of the ETFO planning hierarchy.

**Differentiation**  
Adapting instruction to meet the diverse learning needs of all students in the classroom.

**ETFO (Elementary Teachers' Federation of Ontario)**  
Professional organization representing elementary teachers in Ontario, which developed the 5-level planning hierarchy.

**ETFO 5-Level Planning Hierarchy**  
The complete planning framework: Curriculum Expectations → Long-Range Plans → Unit Plans → Lesson Plans → Daybook Entries.

**Learning Goal**  
A clear statement of what students are expected to learn, written in student-friendly language.

**Learning Skills**  
Six areas of personal and academic skills: Responsibility, Organization, Independent Work, Collaboration, Initiative, Self-Regulation.

**Long-Range Plan**  
Year-long curriculum planning document that maps out the scope and sequence of learning for an entire academic year.

**Minds On**  
The first part of ETFO's three-part lesson structure designed to activate prior knowledge and engage students.

**Action**  
The second part of ETFO's three-part lesson structure where students engage with new learning through various activities.

**Consolidation**  
The third part of ETFO's three-part lesson structure where students reflect on and demonstrate their learning.

**Success Criteria**  
Specific descriptions of what success looks like, helping students understand how to achieve learning goals.

**Three-Part Lesson Structure**  
ETFO's recommended lesson format: Minds On (engagement) → Action (learning) → Consolidation (reflection).

**Unit Plan**  
Multi-week planning document that organizes related learning experiences around a central theme or concept.

### Technical & Development Terminology

**API (Application Programming Interface)**  
Set of protocols and tools for building software applications, allowing different systems to communicate.

**AI Activity Generator**  
Teaching Engine 2.0 feature that uses artificial intelligence to suggest developmentally appropriate activities for curriculum outcomes.

**Containerization**  
Technology (like Docker) that packages applications with their dependencies for consistent deployment across environments.

**CRUD Operations**  
Create, Read, Update, Delete - the four basic functions of persistent storage in database applications.

**Database Migration**  
Process of transferring data between storage types, database schemas, or database instances.

**Docker**  
Platform for developing, shipping, and running applications using containerization technology.

**E2E Testing (End-to-End Testing)**  
Testing methodology that validates the entire application flow from start to finish.

**Express.js**  
Web application framework for Node.js designed for building web applications and APIs.

**JWT (JSON Web Token)**  
Compact, URL-safe token format for representing claims securely between parties.

**Microservices**  
Architectural style that structures an application as a collection of loosely coupled services.

**Node.js**  
JavaScript runtime built on Chrome's V8 JavaScript engine for server-side development.

**ORM (Object-Relational Mapping)**  
Programming technique for converting data between incompatible type systems using object-oriented programming languages.

**PostgreSQL**  
Open-source relational database management system emphasizing extensibility and SQL compliance.

**Prisma**  
Next-generation ORM for Node.js and TypeScript that provides type-safe database access.

**React**  
JavaScript library for building user interfaces, particularly web applications with component-based architecture.

**REST (Representational State Transfer)**  
Architectural style for distributed hypermedia systems, commonly used for web APIs.

**SQLite**  
Self-contained, serverless, zero-configuration SQL database engine.

**TypeScript**  
Programming language that builds on JavaScript by adding static type definitions.

**Vite**  
Build tool that provides faster and leaner development experience for modern web projects.

### Security & Compliance Terminology

**CORS (Cross-Origin Resource Sharing)**  
Mechanism that allows restricted resources on a web page to be requested from another domain.

**FERPA (Family Educational Rights and Privacy Act)**  
U.S. federal law that protects the privacy of student education records.

**HTTPS (Hypertext Transfer Protocol Secure)**  
Extension of HTTP with encryption using TLS/SSL for secure communication over networks.

**Multi-Factor Authentication (MFA)**  
Authentication method that requires user to provide two or more verification factors.

**PIPEDA (Personal Information Protection and Electronic Documents Act)**  
Canadian federal privacy law governing collection, use, and disclosure of personal information.

**Rate Limiting**  
Strategy for limiting network traffic by restricting the number of requests a user can make in a given timeframe.

**SQL Injection**  
Code injection technique used to attack data-driven applications by inserting malicious SQL statements.

**SSL/TLS (Secure Sockets Layer/Transport Layer Security)**  
Cryptographic protocols designed to provide communications security over a computer network.

**XSS (Cross-Site Scripting)**  
Type of security vulnerability found in web applications that enables attackers to inject client-side scripts.

### Teaching Engine 2.0 Specific Terms

**Activity Clustering**  
AI-powered feature that groups related curriculum outcomes for thematic unit planning.

**Coverage Analytics**  
Real-time tracking and visualization of curriculum expectation coverage across the academic year.

**Emergency Sub Plans**  
One-click generation of comprehensive substitute teacher documentation including lesson plans and student information.

**Newsletter Generator**  
Automated creation of parent newsletters based on completed activities and learning progress.

**Outcome Mapping**  
Process of aligning activities and assessments to specific curriculum expectations.

**Planning Automation**  
AI-assisted generation of lesson plans, unit plans, and weekly schedules based on curriculum requirements.

**Resource Integration**  
System for organizing and linking digital resources (files, images, videos) to curriculum content.

**Weekly Planner**  
Visual calendar interface for organizing and scheduling daily lessons within weekly timeframes.

### Performance & Monitoring Terms

**Cache Hit Rate**  
Percentage of requests served from cache rather than the original data source.

**Database Query Optimization**  
Process of improving database query performance through indexing, query rewriting, and schema design.

**Health Check Endpoint**  
API endpoint that provides status information about system health and availability.

**Load Balancing**  
Distribution of incoming network traffic across multiple servers to ensure reliability and performance.

**Response Time**  
Time taken for a system to respond to a request, measured from request initiation to response completion.

**Uptime**  
Percentage of time a system is operational and available for use.

### Integration & Workflow Terms

**Batch Processing**  
Execution of a series of jobs in a computer program without manual intervention.

**Data Synchronization**  
Process of establishing data consistency between multiple data sources.

**LMS (Learning Management System)**  
Software application for administration, documentation, tracking, and delivery of educational courses.

**SIS (Student Information System)**  
Software application for managing student data in educational institutions.

**Webhook**  
Method of augmenting or altering web page or application behavior with custom callbacks.

**Workflow Automation**  
Use of technology to automate complex business processes and functions beyond simple individual tasks.
