# 📚 Teaching Engine 2.0 Documentation

## Overview
This directory contains all documentation for the Teaching Engine 2.0 project, organized by category for easy navigation.

## Directory Structure

### 📋 `/validation/`
**Pedagogical evaluation and assessment tools**
- `PEDAGOGICAL_VALIDATION_CHECKLISTS.md` - Comprehensive checklists for evaluating pedagogical plans
- `INTELLIGENT_EVALUATION_GUIDE.md` - Guide for thoughtful, intelligent assessment (not keyword-based)

### 📁 `/archive/`
**Historical documentation and development artifacts**
- Status reports and assessments from development
- Implementation plans and progress tracking
- Critical assessments and perfection tracking

### 📝 `/planning/`
**Unit and lesson planning documentation**
- Phase documentation (phase1-5 for each subject)
- Detailed unit plans for all subjects
- Cross-curricular planning guides
- Enhancement and validation reports

### 📅 `/calendar/`
**School calendar and scheduling**
- PEI 2025-2026 school calendar
- Complete calendar with holidays and PD days

### 🖥️ `/system/`
**Technical and system documentation**
- Emily teaching assistant documentation
- System state and technical reports
- Implementation guides

## Documentation Philosophy

This project has transitioned from automated keyword-based evaluation to **intelligent human assessment** of pedagogical quality. All evaluation should focus on:

- **Evidence over keywords** - Look for actual implementation, not just mentions
- **Integration over isolation** - Elements should work together cohesively
- **Context awareness** - Consider the specific teaching environment
- **Student impact** - Focus on likely effects on student learning
- **Professional judgment** - Apply educational expertise thoughtfully
