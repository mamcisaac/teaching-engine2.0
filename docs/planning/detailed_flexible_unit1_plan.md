# Detailed Flexible Learning Unit 1 Plan
**Library Orientation & Reading Discovery**

---

## 📋 Unit Overview

**Duration**: September 4-30, 2025 (35 hours)  
**Grade Level**: Grade 1 French Immersion  
**Integration Focus**: Foundational library skills and reading discovery  
**Quality Foundation**: 98/100 from Phase 2 validation  

**Mission**: Establish the library as students' learning home base while building foundational reading skills, choice-making abilities, and cross-curricular connections that will support the entire school year.

---

## 🎯 Unit Objectives & Outcomes

### Primary Learning Goals
1. **Library Citizenship**: Develop responsible library use and community respect
2. **Reading Discovery**: Explore personal reading interests and preferences
3. **Independent Learning Skills**: Build choice-making and self-direction foundations
4. **Cross-Curricular Connections**: Establish library as hub for all subject learning
5. **Technology Integration**: Introduce basic digital literacy and iPad navigation

### Curriculum Connections
**Français langue première**: Reading comprehension, oral communication, vocabulary development  
**Mathématiques**: Counting, sorting, organization systems, patterns  
**Sciences de la nature**: Observation skills, classification, library ecosystem  
**Sciences humaines**: Community resources, library as community space  
**Arts visuels**: Book illustration appreciation, visual storytelling  
**Formation personnelle et sociale**: Responsibility, respect, community belonging

## 📅 Weekly Breakdown (35 hours total)

### **Week 1 (September 4-8): Welcome to Our Learning Home**
*Hours: 8 hours (includes longer orientation sessions)*

**Morning Block (1 hour)**:
- Grand library welcome circle
- Interactive library tour with treasure hunt elements
- Introduction to library mascot/character

**Afternoon Block (1 hour)**:
- Hands-on exploration of different library sections

**Activities**:

## 🏛️ Library Protocols & Procedures

### **Library Citizenship Development**

#### **Week 1-2: Basic Protocols**
- Quiet voices and respectful movement
- Proper book handling and care
- Check-out and return procedures
- Library space respect and organization

#### **Week 3-4: Advanced Citizenship**
- Helping classmates find books
- Maintaining library organization
- Reporting damaged books appropriately
- Being a positive library community member

### **Book Care Procedures**
1. **Clean hands** before handling books
2. **Turn pages gently** from the top corner
3. **No writing** in library books
4. **Keep books dry** and away from food/drinks
5. **Store books flat** or standing up properly
6. **Report problems** to teacher or librarian immediately

### **Library Navigation System**
- **Color-coded sections** for easy identification
- **Picture labels** for non-readers
- **Student helper system** for peer support
- **Class library map** for independent navigation
