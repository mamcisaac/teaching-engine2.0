# Agent Best Practices for Lesson Quality Improvement

## CRITICAL SUCCESS PRINCIPLES

### 1. READ, DON'T ASSUME
- **ALWAYS** read the actual lesson content before making changes
- **NEVER** work from patterns, keywords, or assumptions
- **UNDERSTAND** what the lesson is actually teaching before suggesting materials

### 2. CONTEXT IS EVERYTHING
- **Grade 1 French Immersion**: All content must be developmentally appropriate for 6-7 year olds
- **French Language**: Use French vocabulary and concepts throughout
- **PEI Curriculum**: Materials must support actual curriculum expectations
- **Classroom Reality**: Materials must be realistic for teachers to obtain and use

### 3. QUALITY OVER QUANTITY
- Better to have 2 perfect materials than 5 mediocre ones
- Each material must have a clear pedagogical purpose
- Avoid redundancy - don't suggest the same item multiple times unless truly needed

### 4. SPECIFICITY IS KEY
- Generic materials like "Matériel de base" are FORBIDDEN
- Materials must match the specific lesson activity
- Decision points must address real teaching scenarios for that lesson
- Quantities must be realistic and specific

### 5. TEACHER UTILITY FOCUS
- Teachers should understand the lesson from reading the materials list
- Preparation instructions must be clear and doable
- Alternatives must be genuinely useful, not just different words

## MATERIAL REQUIREMENTS CHECKLIST

✅ **Specificity**: Does this material support the specific learning goal of THIS lesson?
✅ **Appropriateness**: Is this suitable for Grade 1 students (6-7 years old)?
✅ **Accessibility**: Can a teacher reasonably obtain this material?
✅ **Quantity**: Is the quantity realistic and specific?
✅ **Preparation**: Are setup instructions clear and feasible?
✅ **Alternatives**: Are the 3 alternatives genuinely different and useful?
✅ **French Context**: Does this support French immersion learning?

## DECISION POINTS REQUIREMENTS CHECKLIST

✅ **Relevance**: Does this decision point address a real scenario for THIS lesson?
✅ **Actionability**: Does it give teachers clear guidance on what to do?
✅ **Specificity**: Is it specific to this lesson's content and goals?
✅ **Language**: Is it written in French for French immersion lessons?
✅ **Realism**: Would teachers actually encounter this situation?

## COMMON MISTAKES TO AVOID

❌ **Template Thinking**: Don't replace "Matériel de base" with another generic item
❌ **Pattern Matching**: Don't assume similar lessons need identical materials  
❌ **Keyword Searching**: Don't work from superficial text analysis
❌ **Quantity Copying**: Don't reuse the same quantities across different activities
❌ **Generic Alternatives**: Don't provide meaningless alternative options
❌ **English Creep**: Don't use English labels in French immersion content

## AGENT COMMUNICATION PROTOCOLS

### When Starting
1. Confirm you understand your specific task
2. Identify which files you will analyze
3. Read this best practices document completely
4. Review any specific instructions for your agent type

### During Analysis
1. Document your findings clearly
2. Note any exceptional cases or challenges
3. Ask clarifying questions if task scope is unclear
4. Stay within your assigned subject/file boundaries

### When Reporting
1. Use the specific checklist for your agent type
2. Provide clear, actionable recommendations
3. Include specific examples of current problems
4. Suggest concrete improvements with rationale

## QUALITY STANDARDS

### Excellent Material Description Example:
```json
{
  "item": "Cadres de dix plastifiés avec points mobiles",
  "quantity": "2 par élève (50 cadres total)",
  "preparation": "Plastifier cadres, découper cercles magnétiques rouges, placer 5 de chaque couleur avec chaque cadre",
  "alternatives": [
    "Boîtes d'œufs coupées à 10 compartiments avec billes",
    "Grilles de 10 dessinées sur papier avec jetons",
    "Applications tablette de cadres de dix interactifs"
  ]
}
```

### Excellent Decision Point Example:
```
"Si les élèves ont de la difficulté à visualiser 'plus que' → utiliser objets concrets pour comparaison physique avec gestes clairs"
```

### Poor Examples to Avoid:
- "Matériel de base pour l'activité" (too generic)
- "25 unités" (meaningless quantity)
- "Alternative 1, Alternative 2" (not real alternatives)
- "If students struggle → help them" (not actionable)

Remember: Teachers and students depend on the quality of your work. Every improvement makes real classrooms better.
