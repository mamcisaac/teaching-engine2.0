# Learning Goals Improvement Pattern for Grade 1 French Immersion

## Current Issues Identified

### Problematic Learning Goals Examples:
- ❌ "Students will learn basic French greetings and identify 5 classroom objects in French"
- ❌ "Students will count objects to 10 in French and identify basic colors"

### Problems with Current Format:
1. **Vague verbs**: "learn", "identify" are not specific enough
2. **Wrong structure**: Uses "will" instead of "can"
3. **Not measurable**: Hard to observe if students have "learned"
4. **Not Grade 1 specific**: Too abstract for 6-year-olds

## Improved Learning Goals Pattern

### Formula: "Students can [ACTION VERB] [SPECIFIC BEHAVIOR] [WITH WHAT/HOW]"

### Grade 1 Approved Action Verbs:
- **Physical Actions**: point to, touch, draw, color, cut, paste
- **Counting**: count, match, sort, group, arrange
- **Speaking**: say, repeat, name, tell, ask
- **Recognition**: find, choose, pick, show, circle
- **Simple Creation**: make, build, create (simple)

### Improved Examples:

#### French Language Arts:
- ✅ **Before**: "Students will learn basic French greetings"
- ✅ **After**: "Students can say 3 French greetings (Bonjour, Salut, Bonsoir) to a classmate"

- ✅ **Before**: "Students will identify classroom objects"
- ✅ **After**: "Students can point to and name 5 classroom objects in French when asked"

#### Mathematics:
- ✅ **Before**: "Students will count objects to 10"
- ✅ **After**: "Students can count 10 objects by pointing to each one and saying the French number"

- ✅ **Before**: "Students will identify basic colors"
- ✅ **After**: "Students can match 6 color words (rouge, bleu, vert, jaune, noir, blanc) to colored objects"

#### Science:
- ✅ **Before**: "Students will understand weather"
- ✅ **After**: "Students can draw and name 4 types of weather (soleil, pluie, neige, nuages) in French"

#### Arts:
- ✅ **Before**: "Students will create art"
- ✅ **After**: "Students can use 3 different art materials (crayon, peinture, papier) to make a self-portrait"

### Quality Checklist for Learning Goals:

1. ✅ **Starts with "Students can..."**
2. ✅ **Uses Grade 1 appropriate action verb**
3. ✅ **Includes specific number/quantity when possible**
4. ✅ **Observable behavior (teacher can see/hear it)**
5. ✅ **Achievable in 45 minutes**
6. ✅ **French immersion appropriate**

### Template for Different Subject Areas:

#### French Language Arts:
"Students can [say/repeat/point to/match] [specific French words/phrases] [in what context]"

#### Mathematics (in French):
"Students can [count/sort/match/group] [specific quantity] [of what objects] [using French numbers]"

#### Science (in French):
"Students can [draw/name/show/find] [specific number] [of what items/concepts] [in French]"

#### Arts (in French):
"Students can [use/create/make] [specific materials/techniques] [to create what] [while using French vocabulary]"

#### Social Studies/Health (in French):
"Students can [name/show/draw] [specific concepts] [about what topic] [using French words]"

## Implementation Notes:

- Each lesson should have ONE primary learning goal
- Goal should be achievable in one 45-minute lesson
- Must be observable and measurable
- Should connect to curriculum expectations
- French vocabulary should be age-appropriate for Grade 1
- Goals should build on previous lessons
