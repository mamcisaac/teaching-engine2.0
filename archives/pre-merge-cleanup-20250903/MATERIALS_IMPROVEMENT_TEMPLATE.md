# Complete Materials List Template - Phase 4

## Template Structure for ALL Lesson Materials

Each lesson section (opening, main, closing) should have materials specified as:

```json
"materials": {
  "required": [
    {
      "item": "Specific item name",
      "quantity": "Exact number per student/group/class",
      "preparation": "What to prepare in advance",
      "alternatives": ["Budget-friendly option 1", "Option 2"],
      "safety": "Safety notes if applicable"
    }
  ],
  "optional": [
    {
      "item": "Enhancement item",
      "quantity": "Number needed",
      "purpose": "Why this helps"
    }
  ]
}
```

## Subject-Specific Requirements

### Mathematics
**Must Include:**
- Exact quantities: "20 counting blocks per student" not "blocks"
- Manipulative alternatives: "20 beans/buttons if no blocks available"
- Visual aid specifications: "Number line 0-20 (1 per student, laminated)"
- Group size specifications: "1 set per pair (2 students)"

**Example:**
```json
"materials": {
  "required": [
    {
      "item": "Base-10 blocks (tens and ones)",
      "quantity": "1 ten-block and 5 one-blocks per student (class set of 25)",
      "preparation": "Pre-count into ziplock bags, 1 bag per student",
      "alternatives": ["20 popsicle sticks bundled in groups of 10", "Drawn ten-frames on paper"],
      "safety": "Check for small pieces with Grade 1 students"
    }
  ]
}
```

### Science
**Must Include:**
- Safety equipment: "Safety goggles (1 per student)" 
- Observation tools: "Hand magnifying glass (1 per pair)"
- Clean-up materials: "Paper towels, wet wipes"
- Emergency procedures: Reference to safety protocols

### Arts
**Must Include:**
- Alternatives for expensive items
- Clean-up materials
- Aprons/protection
- Storage solutions

### French Language
**Must Include:**
- Vocabulary cards with visuals
- Puppets or character props
- Audio equipment specifications
- Visual supports with quantities

### Social Studies
**Must Include:**
- Maps, photos, cultural artifacts
- Community connection materials
- Visual displays

### Health/FPS
**Must Include:**
- Emotion cards with visuals
- Safety equipment
- Role-play props
- Comfort items

## Key Principles

1. **SPECIFIC QUANTITIES**: Always specify per student, per pair, per group, or per class
2. **PREPARATION NOTES**: What needs to be done before the lesson starts
3. **ALTERNATIVES**: Budget-friendly options for expensive items
4. **SAFETY**: Include safety equipment and notes where needed
5. **FRENCH SUPPORT**: All lessons need visual vocabulary supports
6. **GRADE 1 APPROPRIATE**: Consider size, safety, developmental level

## Common Improvements Needed

### BEFORE (Bad Examples):
- "blocks" → "20 counting blocks per student"
- "paper" → "Chart paper (1 sheet), lined paper (1 per student)"
- "materials": [] → Complete materials list
- "magnifying glasses" → "Hand magnifiers (1 per pair, 12 total)"

### AFTER (Good Examples):
- "20 counting blocks per student (alternative: dried beans or buttons)"
- "Chart paper (1 large sheet for class display), lined paper (1 per student, 25 sheets total)"
- Complete materials list with quantities and alternatives
- "Hand magnifiers (1 per pair, 12 total for class of 24, stored in science bin)"

## Quality Check Questions

1. Could a substitute teacher gather all materials without asking questions?
2. Are quantities specific enough for ordering/preparation?
3. Are there alternatives for expensive items?
4. Is safety equipment included where needed?
5. Are French visual supports specified?
6. Is preparation time accounted for?

This template ensures teachers know EXACTLY what to prepare for successful lesson delivery.
