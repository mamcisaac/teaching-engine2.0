# Materials Quality Improvement Plan

## Current Problem
Every lesson in every file has the SAME materials repeated:
- amities-full.json: 57× "Cartes scénarios sociaux d'amitié" 
- nutrition-full.json: 56× "Modèles aliments Guide alimentaire"
- Math files: 34× "Cadres de dix plastifiés"

This is useless - a lesson about sharing needs sharing materials, not friendship cards!

## Solution Pattern

### For Amities (Friendship) Unit:

**Lesson 1: "What is a friend?"**
- Opening: Photos of diverse friendships
- Main: Friendship definition cards, role-play puppets
- Closing: "A friend is..." completion cards

**Lesson 4: "Sharing is important"** 
- Opening: Limited toys to create sharing need (15 toys for 25 students)
- Main: Turn-taking timer, sharing tokens
- Closing: Sharing recognition badges

**Lesson 10: "Solving problems"**
- Opening: Conflict resolution wheel
- Main: Peace corner with calm-down tools
- Closing: Peaceful resolution certificates

### For Nutrition Unit:

**Lesson 1: "What is nutrition?"**
- Opening: Mystery foods to explore
- Main: Food group sorting bins
- Closing: "My body needs..." chart

**Lesson 5: "Healthy snacks"**
- Opening: Snack samples (with permissions)
- Main: Snack preparation tools (safe knives, boards)
- Closing: Recipe cards to take home

**Lesson 10: "Exercise and movement"**
- Opening: Movement cards
- Main: Exercise equipment (hoops, balls, ropes)
- Closing: Activity tracking chart

### For Math Unit:

**Lesson 1: "Discovering 11-20"**
- Opening: Collections of 11-20 objects
- Main: Ten frames (appropriate here!)
- Closing: Number cards 11-20

**Lesson 5: "Comparing numbers"**
- Opening: Comparison cards
- Main: Balance scales (not ten frames!)
- Closing: Greater/less than symbols

**Lesson 10: "Writing numbers"**
- Opening: Number formation cards
- Main: Writing boards and markers
- Closing: Number certificates

## Implementation Requirements

Each lesson needs:
1. Materials that match its ACTUAL activity
2. Different items for opening/main/closing when appropriate
3. Realistic quantities and preparation
4. Genuine alternatives (not "Alternative 1,2,3")

## Quality Metrics

✅ Good: Maximum 3-4 repetitions of any material in a file
❌ Bad: 57 repetitions of the same item

✅ Good: "Limited toys (15 for 25 students) to create sharing situations"
❌ Bad: "25 units (one for each student)"

✅ Good: Lesson-specific materials that reveal the activity
❌ Bad: Generic materials that could apply to anything
