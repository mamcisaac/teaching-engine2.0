## ✅ Enhancements Applied

### 1. Decision Points Added (0-3 per lesson)
**ETFO Principle**: "Support teacher thinking, not replace it"

**Simple, actionable guidance added**:
```
Opening:
- "Si les élèves ne comprennent pas le vocabulaire → ajouter gestes et images"
- "Si l'engagement est faible → incorporer plus de mouvement"

Main:
- "Si les élèves maîtrisent rapidement → offrir activité d'extension"
- "Si difficulté avec la tâche → simplifier en étapes plus petites"

Closing:
- "Si temps insuffisant → prioriser le partage oral"
```

**Not forced** - added based on lesson complexity:
- Early lessons (1-5): More guidance (2-3 points)
- Middle lessons (6-15): Balanced (1-2 points)
- Later lessons (16-20): Minimal (0-1 points)

### 2. Materials Specified
**Replaced generic terms** with specific classroom items:
- ❌ "Matériel de base pour l'activité"
- ✅ "Cubes emboîtables ou jetons, 20 par élève, Bac mathématiques"

**Subject-specific materials**:
- **Math**: Manipulatives, counters, geometric blocks
- **French**: Vocabulary cards, writing notebooks, word wall
- **Science**: Magnifying glasses, observation containers
- **Arts**: Drawing paper, colored pencils, paint
- **Social Studies**: Community maps and images
- **Health/PE**: Gym equipment, hoops, soft balls

### 3. Language Compliance
**Fixed mixed English/French in goals**:
- "Students discover" → "Les élèves découvrent"
- "will be able to" → "pourront"
- "understand" → "comprendre"

**Note**: Some complex phrases need manual review for natural French flow
