## LESSON DISTRIBUTION FRAMEWORK

### Optimal 45-Minute Lesson Structure for Grade 1
```
MINDS ON (8 minutes):
- Number talk or warm-up game
- Review previous learning
- Activate prior knowledge
- Set learning intention

ACTION (30 minutes):
- Introduction of new concept (5 min)
- Hands-on exploration (20 min)
- Practice and application (5 min)

CONSOLIDATION (7 minutes):
- Share discoveries
- Reflect on learning
- Preview next steps
- Assessment opportunity
```

### Weekly Pattern Suggestion
- **Day 1:** New concept introduction
- **Day 2:** Practice and exploration  
- **Day 3:** Application and problem-solving
- **Day 4:** Consolidation and assessment
- **Day 5:** Extension or remediation
