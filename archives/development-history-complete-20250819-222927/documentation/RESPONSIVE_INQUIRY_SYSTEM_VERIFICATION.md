## 🏗️ SYSTEM ARCHITECTURE

### **1. RESPONSIVE INQUIRY STRUCTURE**
```
EVERY LESSON (45 minutes):
├── Minds On (8 min): Wonder moment + learning goal
├── Action (27 min): 
│   ├── Core Investigation (15 min) - ALL students
│   └── Extension Options (12 min) - RESPONSIVE to engagement
└── Consolidation (10 min): Reflect + document + preview
```

**The Genius**: Structure provides security, flexibility provides responsiveness.

### **2. THREE-TIER FLEXIBILITY SYSTEM**
```
HIGH ENGAGEMENT → Use all extensions, let learning run deep
NORMAL ENGAGEMENT → Follow standard structure with 1-2 extensions  
LOW ENGAGEMENT → Core investigation only + supportive adaptations
```

**The Genius**: Same learning objectives, different pathways based on real student needs.

### **3. SAFETY-FIRST DESIGN**
```
EVERY LESSON INCLUDES:
├── Safety protocol review
├── Age-appropriate safety practices
├── Emergency procedures integration
└── Safety assessment through observation
```

**The Genius**: Safety isn't added on - it's built into the learning structure.
