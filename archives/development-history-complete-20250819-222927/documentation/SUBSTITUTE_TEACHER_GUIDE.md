## 📚 LESSON STRUCTURE GUIDE

### **MINDS ON (8 minutes) - Getting Started**

**Your Role:**
- Gather students in circle time area
- Ask the "wonder question" provided in lesson plan
- Get students thinking about today's investigation
- State the learning goal clearly

**Student Expectations:**
- Sit in circle, contribute ideas
- Listen to classmates
- Ask questions
- Get excited about learning

**French Support:**
- Key phrases are provided in lesson plans
- Students can respond in English if needed
- Encourage French but don't force it

**If Students Are Wiggly:**
- Add movement: stand up, sit down, wiggle fingers
- Keep it short - 6 minutes is fine
- Preview the hands-on action coming

### **ACTION (27 minutes) - Main Investigation**

**ALWAYS INCLUDES TWO PARTS:**

#### **Core Investigation (15 minutes) - ALL STUDENTS MUST DO THIS**
- This is the essential learning activity
- Every student participates
- Materials are prepared and ready
- Safety protocols are clearly posted

#### **Extension Options (12 minutes) - USE YOUR JUDGMENT**

**HIGH ENGAGEMENT** - Students are excited and focused:
- Use Extension Option A, B, or C from lesson plan
- Let them continue investigating
- Add challenge materials provided

**NORMAL ENGAGEMENT** - Students are working well:
- Complete core investigation
- Add one simple extension if time allows
- Use extra time for sharing discoveries

**LOW ENGAGEMENT** - Students are tired/unfocused:
- Focus only on core investigation
- Shorten to 12-15 minutes if needed
- Use calm, supportive voice
- Provide extra adult support if available

**Weather/Emergency Adaptations:**
- Indoor alternatives are provided for outdoor lessons
- Emergency backup lessons in red folder
- Simplified versions available for all activities

### **CONSOLIDATION (10 minutes) - Wrap Up Learning**

**Your Role:**
- Bring students back to circle
- Ask reflection questions provided
- Help with science journal entries
- Preview tomorrow (if known)
- Ensure safe cleanup

**Student Expectations:**
- Share one discovery or thought
- Complete science journal entry (drawing + words)
- Help with cleanup
- Prepare for next class

**Assessment Notes:**
- Fill out simple observation form (provided)
- Note any safety concerns
- Record interesting student discoveries
- Leave notes for Emily

## 🚨 EMERGENCY PROTOCOLS

### **If a Student Gets Hurt:**
1. **Stay Calm** - reassure student
2. **Assess Injury** - minor (band-aid) or serious (office)
3. **First Aid Kit** - located [location to be filled by Emily]
4. **Contact Office** - for anything beyond minor scrape
5. **Document** - fill out incident report
6. **Continue Safely** - modify activity if needed

### **If Materials Break/Spill:**
1. **Student Safety First** - move students away
2. **Clean Up** - use provided cleaning supplies
3. **Continue Learning** - adapt activity as needed
4. **Note for Emily** - record what happened

### **If Students Are Difficult to Manage:**
1. **Safety First** - ensure all students are safe
2. **Simplify Activity** - use adaptation options
3. **Get Help** - call office if needed
4. **Document** - note challenges for Emily

### **Severe Weather/Emergency:**
1. **Follow School Procedures** - posted on wall
2. **Keep Students Calm** - reassuring voice
3. **Account for All Students** - use class list
4. **Follow Administrator Directions**

## 💬 FRENCH IMMERSION SUPPORT

### **Key Daily Phrases:**
- "Bonjour, scientifiques!" (Hello, scientists!)
- "Qu'est-ce que nous observons?" (What do we observe?)
- "Soyez prudents!" (Be careful!)
- "Très bien!" (Very good!)
- "C'est l'heure de nettoyer" (It's cleanup time)

### **Science Vocabulary (Unit 1):**
- **vivant** (living) - "vee-VAHN"
- **non-vivant** (non-living) - "nohn vee-VAHN"
- **observer** (to observe) - "ohb-zair-VAY"
- **sécurité** (safety) - "say-kur-ee-TAY"

### **Support Strategies:**
- Visual cues and gestures help communication
- Students can respond in English when needed
- Praise attempts at French pronunciation
- Use cognates (words similar to English) when possible

## 🔄 ADAPTATION QUICK REFERENCE

### **High Energy Day:**
- Add movement to Minds On
- Use all extension options
- Let investigations run longer
- Channel energy into exploration

### **Low Energy Day:**
- Shorter Minds On (6 minutes)
- Core investigation only
- More adult guidance
- Calmer consolidation

### **Weather Issues:**
- Indoor alternatives provided in lesson plans
- Window observations instead of outdoor walks
- Modify materials but keep learning goals

### **Time Running Short:**
- Skip extensions, focus on core
- Quick consolidation (7 minutes)
- Save reflection for tomorrow's Minds On

### **Time Running Long:**
- Extend consolidation for deeper reflection
- Allow more sharing time
- Connect to other subject areas
