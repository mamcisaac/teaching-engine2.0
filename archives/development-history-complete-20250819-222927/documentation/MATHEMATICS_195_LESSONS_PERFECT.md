Emily McIsaac's Grade 1 French Immersion Mathematics program now has **exactly 195 lessons** structured with the revolutionary **Core + Extension model** - providing perfect balance between curricular requirements and classroom flexibility.

## The Perfect Structure

### Units 1-5: 20 Lessons Each (100 total)

- **Extension Lessons**: 6 per unit (30%) - Flexible enrichment and application

### Units 6-10: 19 Lessons Each (95 total)

## The Revolutionary Core + Extension Model

### CORE LESSONS (70% - Essential)
**What they are:**
- Fundamental concepts all students must master
- Direct curriculum expectation coverage
- Prerequisites for next unit
- Non-negotiable learning objectives

**Example - Unit 1 Core (14 lessons):**
- Diagnostic and number exploration (2)
- Counting and one-to-one correspondence (3) 
- Subitizing 1-5 instant recognition (3)
- Number formation and writing 0-5 (2)
- Extension to numbers 6-10 (2)
- Comparison and ordering 0-10 (2)

### EXTENSION LESSONS (30% - Flexible)
**What they are:**
- Enrichment and application activities
- Creative and artistic connections
- Challenge problems for advanced learners
- Additional practice for struggling students
- Real-world problem solving
- Celebration and portfolio activities

**Example - Unit 1 Extensions (6 lessons):**
- Number games and daily applications (2)
- Advanced subitizing challenges (1)
- Real-world problems (counting snacks) (1)
- Personal number book creation (1)
- Celebration and learning portfolio (1)

## Built-In Differentiation

### For Struggling Students:
- **Priority**: Complete all core lessons with support
- **Extension use**: Additional practice and reinforcement
- **Time**: Use extension lessons for reteaching
- **Assessment**: Focus on essential objectives

### For On-Level Students:
- **Priority**: Complete cores + selected extensions
- **Extension use**: Application and creative projects
- **Time**: Balance challenge with mastery
- **Assessment**: Full range of objectives

### For Advanced Students:
- **Priority**: Quick through cores + all extensions
- **Extension use**: Challenge problems and leadership
- **Time**: Create additional challenges
- **Assessment**: Extension and creation tasks

### For French Language Learners:
- **Priority**: Cores with language support
- **Extension use**: Vocabulary building activities
- **Time**: Balance content and language development
- **Assessment**: Multiple ways to demonstrate knowledge
