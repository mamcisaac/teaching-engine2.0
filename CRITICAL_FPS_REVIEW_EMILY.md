## DETAILED ETFO COMPLIANCE REQUIREMENTS

### 1. DURATION REQUIREMENT
**Standard:** 45 minutes per lesson  
**Current Status:** ALL lessons are 60 minutes  
**Required Action:** Reduce ALL 96 lessons from 60 to 45 minutes

### 2. STRUCTURE TIMING REQUIREMENTS
**Standard:** 
- MindsOn: 8 minutes
- Action: 27 minutes  
- Consolidation: 10 minutes

**Current Status:** Structure components present but no timing specified  
**Required Action:** Add timing breakdown to ALL 96 lessons

### 3. DIFFERENTIATION REQUIREMENTS
**Standard:** JSON format with 4 types:
```json
{
  "support": "Strategies for struggling learners",
  "extension": "Enrichment for advanced learners", 
  "multiModal": "Various learning modalities",
  "accommodations": "Specific learning needs support"
}
```
**Current Status:** Missing from ALL lessons  
**Required Action:** Add differentiation JSON to ALL 96 lessons

### 4. FRENCH VOCABULARY REQUIREMENTS
**Standard:** 2-3 Grade 1 appropriate French terms per lesson  
**Current Status:** Missing from ALL lessons  
**Required Action:** Add vocabularyFr field to ALL 96 lessons

### 5. INDIGENOUS PERSPECTIVES REQUIREMENTS
**Standard:** 100+ characters of meaningful Indigenous content  
**Current Status:** Missing from ALL lessons  
**Required Action:** Add Indigenous perspectives to ALL 96 lessons

### 6. OBSERVABLE ASSESSMENT REQUIREMENTS
**Standard:** ☐ checkbox format for observations
```
☐ Student demonstrates understanding of body safety
☐ Student uses appropriate French vocabulary
☐ Student shows respect for Indigenous perspectives
```
**Current Status:** Text-based assessment notes  
**Required Action:** Convert ALL 96 lesson assessments to observable format
