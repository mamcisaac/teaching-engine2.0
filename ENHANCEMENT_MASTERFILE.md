## 📝 Enhancement Process (For Each Unit)

### Step 1: Agent Reads Unit File
```bash
# Agent reads and comprehends all 20 lessons
Read generated-lessons/[subject]/[unit]-full.json
```

### Step 2: Fix Translations
- Change all "Students will..." → "Les élèves..."
- Ensure natural Canadian French throughout
- Mark: ✅ Translations

### Step 3: Add Decision Points
- Add 0-3 pedagogically meaningful points per lesson
- Early lessons (1-5): 2-3 points
- Middle lessons (6-15): 1-2 points
- Later lessons (16-20): 0-1 points
- Mark: ✅ Decision Points

### Step 4: Specify Materials
- Exact quantities for 20-25 students
- School-available only (NO parent donations)
- Alternative options provided
- Mark: ✅ Materials

### Step 5: Commit Changes
```bash
git add generated-lessons/[subject]/[unit]-full.json
git commit -m "✨ Enhanced [unit]: translations, decision points, materials"
git push origin main
```
- Mark: ✅ Committed

### Step 6: Create Review Feedback
- Save to: `REVIEW_FEEDBACK/[subject]/[unit]-review.md`
- Document strengths and issues
- Mark: ✅ Reviewed
